# isw-233-maca
# INTRODUCCION
En este proyecto se realizo una conexion de tipo tcp para el juego de battleship en consola usando python y lo que es socket para ayudar con la ip, puerto y conexiones
# EXPLICACION
Se debe ejecutar 2 archivos distintos Jugador 1 va a ser el Servidor y Jugador 2 va a ser el cliente, el jugador 1 crea un puerto y una semilla para su tablero randomizado, y el cliente debe ingresar el ip y puerto generados por el servidor, y poner tambien su semilla. Una vez empiezan cada uno selecciona sus casillas con las coordenadas A1 por letra y numero, el que derribe todas las casillas del oponente gana.
